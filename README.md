# 📊 E-Commerce Sales Analysis | SQL & Power BI

## 📌 Project Overview
This project is an end-to-end data analytics project built using the Brazilian E-Commerce (Olist) dataset.

The project demonstrates the complete data analysis process, starting from data cleaning and business analysis using SQL Server, then building an interactive Power BI dashboard to visualize key business insights.

---

## 🛠 Tools & Technologies

- SQL Server
- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

---

## 📂 Project Workflow

### SQL Analysis
- Created the database in SQL Server.
- Imported and validated the dataset.
- Performed data cleaning.
- Wrote 25+ SQL queries for business analysis.
- Analyzed sales, customers, products, sellers, payments, delivery performance, and customer reviews.

### Power BI Dashboard
- Built the data model.
- Created DAX measures.
- Designed an interactive multi-page dashboard.
- Added slicers, drill-through, KPIs, and dynamic filtering.

---

## 📊 Key Insights

- Revenue exceeded **$16M**
- More than **99K orders** were analyzed.
- Average customer review score was approximately **4.1/5**.
- São Paulo (SP) generated the highest revenue.
- Health & Beauty was the top-performing product category.
- Most deliveries were completed on time.
